# Мобильный интерфейс Kana Studio

Локальный UI UX Pro Max: поиск `productivity reader minimal` подтвердил Flat Design для мобильного инструмента; поиск `touch target safe areas` подтвердил цели 48 dp и промежутки 8 dp. Рекомендации маркетинговых страниц из общего поиска не применяются к нативному приложению. Сохранены зелёная палитра и спокойное оформление Windows-версии. Используются системные шрифты, без загрузок.

- Три постоянные вкладки: текст, чтение, слоги. Системная кнопка «Назад» возвращает к тексту, затем закрывает приложение.
- Нативные кнопки с ripple, цели от 48 dp, карточки со скруглением 20 dp, отступы 4/8/16/24 dp.
- Чтение занимает главный экран; его параметры скрыты за раскрываемой кнопкой. Подсказки доступны нажатием и отдельным списком.
- Светлая и тёмная темы используют семантические токены. Обычный текст, вторичный текст и текст на выделении должны иметь контраст не ниже 4,5:1.
- Системные панели, вырез и клавиатура учитываются через WindowInsets. На планшете содержимое ограничено шириной 720 dp.
- Текст измеряется в sp, карточки и кнопки растут по содержимому. При крупном шрифте выбор азбуки становится вертикальным, сетка знаков уменьшает количество колонок.
- Никаких декоративных эмодзи, внешних шрифтов и анимаций перемещения. Иконки темы и справки рисуются векторами; у них есть названия для TalkBack.

Проверка: эмулятор Android 15, телефон 375 dp, обе темы, шрифт 200%, альбомная ориентация, планшет 1024 dp, отключённые анимации. Настоящий телефон и TalkBack требуют отдельной ручной проверки.
